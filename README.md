## Course Management System

A console-based academic management system built in C++ as part of a 
Data Structures & Algorithms course project.

The system simulates real-world university course operations using a 
wide range of data structures, each chosen for a specific use case.

## Data Structures Used

| Data Structure | Purpose |

| Singly & Doubly Linked List | Dynamic course enrollment and student records |
| Stack & Queue | Request handling and task scheduling |
| Hash Table | Fast course lookups by course code |
| Graph | Modelling course prerequisites |
| Binary Search Tree (BST) | Sorted course retrieval |
| MaxHeap | Priority-based scheduling |
| QuickSort & MergeSort | Efficient data sorting and organisation |

## Features

- Enroll and drop students from courses
- Manage course prerequisites using graph-based dependency checks
- Search and retrieve courses efficiently using BST and Hash Table
- Schedule tasks by priority using MaxHeap
- Sort records using QuickSort and MergeSort
- Time complexity analysis performed across all operations

## Language & Tools

- IDE: Visual Studio / VS Code
- Concepts: Data Structures, Algorithm Design, Time Complexity Analysis
